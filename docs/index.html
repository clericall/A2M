Why MusicDrop

Built for the files you already own.

No cloud upload, no desktop sync, no repackaged copy of someone else's tweak. MusicDrop reads your file, then hands it to the Music app's own import pipeline.

On-device import

Pick files with the system document picker. Everything happens on the phone, including tagging and artwork.

Tags and art

Reads embedded title, artist, album, genre, year, track numbers, and cover art. Missing art gets a MusicDrop cover.

No PC at runtime

Build once with GitHub Actions. After that, import music from Files whenever you want, without SSH or a cable.

Small and local

A single tweak, a loopback file server, and your existing library. No accounts, analytics, or external uploads.

Install

Add the repo, install, open Music.

Works on rootless jailbreaks that provide MobileSubstrate or ElleKit. The package is built for iphoneos-arm64.

1

Open Sileo, go to Sources, tap Edit, then Add Source and paste this address.

Install MusicDrop

Tap Import in Music

Open Music, tap the pink floating button, and choose audio files from Files or iCloud Drive. Keep Music open while the import finishes.

FAQ

Good to know.

Short answers to the things that usually come up before installing a tweak.

Do I need a computer after installing?

No. The tweak is built and published by GitHub Actions. Your phone downloads the package from this repo, and imports happen entirely on-device.

Where do imported files go?

MusicDrop copies each pick into /var/mobile/Media/MusicDrop/inbox/, reads its metadata, serves it briefly on 127.0.0.1, and asks Music's own download queue to import it. The inbox and artwork folders are pruned after seven days. Imported songs live in your normal Music library.

Why should Music stay open?

The temporary local server runs inside the Music app process. If iOS suspends Music before the store daemon fetches the file, the import can fail. MusicDrop requests extra background time, but keeping Music in the foreground is the reliable option.

Will my songs disappear if I uninstall MusicDrop?

No. Songs already added to the Music library stay there. Uninstalling removes the tweak only; the MusicDrop folder in Media is left alone so you can inspect or delete it with Filza.

Is this a piracy tool?

No. MusicDrop imports audio files you already have. It does not download music, bypass DRM, or talk to anything except this repo and the local Music app. Use it with files you have the right to use.

Something failed. Where is the log?

Open Filza and read /var/mobile/Media/MusicDrop/musicdrop.log. It records the server port, copied files, metadata, and any StoreServices errors. Include the last few lines when asking for help.

Can I rebuild it myself?

Yes. The source is in the repository. Push a change, let the GitHub Actions workflow build the rootless deb, and it will regenerate this index and deploy the page. The generator uses only the Python standard library.
